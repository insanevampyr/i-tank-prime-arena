## Remaining scope and owner testing

The revised Task 36F owner ruling resolves the earlier movement question: downtime walking/Running and combat time remain frozen. The UI button is now COLLECT ALL LOOT. Its authoritative batch collects every eligible uncollected battlefield reward regardless of distance or walls. This is an explicit Arena exception, not printed Prime proximity behavior. Stable world-item IDs are sorted deterministically; each successful item uses the existing collection transaction, retains identity/quantity/provenance, and emits its own causal collection event with the batch policy. A summary event lists successful and blocked entries. The existing accepted-request set rejects replayed batch IDs; previously collected and non-loot world items are skipped. Unknown/incomplete item actions remain blocked even though their valid reward records can be owned. Individual downtime marker pickup retains the prior contact behavior; COLLECT ALL supplies the approved remote batch. No dropped combat spear is collected unless the existing reward system has legitimately transferred it into loot.

Combat marker clicks route to explicit `combat_pickup_requirements_unverified` feedback and do not schedule an attack, movement or free pickup. Verified generic combat-time pickup Act/hand requirements are absent, so only that resolution is gated. No combat pickup mechanic is invented. Batch tests prove distance/wall independence, duplicate protection, no clock/resource changes, NEXT WAVE persistence, RESET, deterministic schema-12 snapshots and two-client convergence.

Headless microbenchmarks do not diagnose the owner's entire intermittent browser lag or instability. The continuation adds short separate profiles for Guard and Vaelis in Waves 1, 3 and 4 (two simulated seconds each): simulation 22-48 ms; event presentation 0.8-1.3 ms; 40 presentation calls 7-16 ms; first transcript 0.9-2.1 ms; 20 cached transcript reads 16-30 us with zero rebuilds. Static memory grew about 351-544 KB while retaining the scenario's authoritative events/state; that is not a leak measurement or a long-match growth diagnosis. Ground path rebuilds were one per actor in these short samples, zero for aerial actors. GPU/browser, editor/debugger and extended-match instability remain unverified.

Continuation tests cover identity-preserving stacked clicks, duplicate collection rejection, out-of-range feedback, no movement/actions from loot clicks, NEXT WAVE continuity, RESET, authoritative digest invariance during rendering, and a thin-wall within-one-foot obstruction.
